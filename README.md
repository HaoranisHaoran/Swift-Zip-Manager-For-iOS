# Swift-Zip-Manager-For-iOS
一个用 Swift 写的压缩文件管理器，极致简洁，仅 384 KB。

✨ 功能

· 支持 ZIP / TAR / GZ / 7z / RAR （正在开发中）
· 语言界面（14 种语言)

📱 平台

· iOS 16.6+
. iPadOS 16.6+
. macOS 13.5+ (Apple Silicon)
. visionOS 1.0+

📦 体积:384 KB（比一张截图还小）
